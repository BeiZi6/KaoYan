# 1080px 移动端长图落地页设计（《被误读的智性恋》）

## 目标
- 将 `社论/1.31.md` 生成一张 1080px 宽的移动端长图，便于公众号插图发布。
- 视觉方向：温和纸感 / 人文随笔，突出社论质感与可读性。

## 视觉方向
- 背景：暖米白纸张基色，微弱纸纤维纹理 + 轻颗粒噪点 + 轻微暗角。
- 版式：大留白、舒缓行距；正文宽度约 720–760px。
- 字体：标题使用衬线体（宋体类），正文使用人文无衬线（苹方类）。
- 色彩：暖灰、浅棕、淡墨绿点缀，克制不艳。

## 结构与组件
- `cover`：封面图 + 标题 + 副标题。
- `summary`：摘要卡片。
- `toc`：目录清单。
- `content`：正文分节（`##` 触发章节块）。
- `closing`：结语强调块。
- `tags`：标签区。

## 内容映射规则（Markdown → HTML）
- `#` → 封面标题。
- `**摘要**` 与后续段落 → 摘要卡片。
- “本文目录”及编号列表 → 目录区。
- `##` → 章节标题块。
- 普通段落 → 正文段落。
- `>` → 引用卡片。
- `---` → 分隔线。
- 图片 `![...]` → 正文插图（封面使用指定图）。

## 数据流
1. 读取 `社论/1.31.md` 并解析为结构化节点。
2. 注入 HTML 模板与 CSS 主题。
3. 无头浏览器渲染为 1080px 宽的长图（自动高度）。
4. 输出 PNG（建议目录：`output/1.31-long.png`）。

## 错误与降级
- 图片缺失：使用占位块并记录提示。
- 非标准列表：降级为普通段落。

## 验收与测试
- HTML 预览检查字号、行距、段间距。
- 长图检查：断行密度、引用卡片溢出、图片裁切。
- 手机预览清晰度确认。

## 约束与假设
- 使用本地系统字体，避免外链字体导致渲染不一致。
- 输出为单张长图，宽度固定 1080px。
