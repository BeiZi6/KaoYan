# 落地展示页设计稿：怀念的回声与现实的回应

## 目标与受众
- 目标：把长文内容做成可读性强、具备“社论档案”气质的落地展示页，移动端与桌面端均能舒适阅读。
- 受众：对公共议题与历史叙事有兴趣的普通读者。
- 成功标准：首屏清晰传达标题与主题，正文阅读连贯，移动端单列排版无视觉压迫感。

## 视觉方向
- 风格：纸质社论 / 编辑部档案风。
- 质感：暖米色纸张底纹 + 轻噪点；深墨色正文；砖红色作为唯一强调色；极淡的线性网格营造“档案页”秩序感。
- 记忆点：首屏“档案编号”侧栏、下沉大首字母、编辑手记式引言块。

## 排版结构
1. **封面区**：大标题、副标题、阅读时长、关键词标签；右侧显示“档案编号/发布日期”。
2. **编辑手记**：一段短引言，作为读者情绪锚点。
3. **正文区**：按原文小标题分段，段落间用细线分隔；首段使用下沉首字母增强仪式感。
4. **收束区**：简短的“延伸思考/分享提示”提示区，不抢戏。

## 交互与动效
- 仅保留轻量动效：首屏与段落渐显 + 轻微上移，避免打断阅读。
- Hover 仅用于链接与小标签，确保庄重克制。

## 技术实现
- 单页 HTML + 内联 CSS。
- 字体：标题用 `Noto Serif SC`，正文用 `Noto Sans SC`。
- 响应式：桌面端双栏封面布局；移动端自动单列，字体与间距自适应。
